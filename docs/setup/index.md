# Setup

These pages show how to make an xtr application and how to add packages to it.
Do them in this sequence:

1. [Install the tools](install.md).
2. [Create an application](new-application.md).
3. [Add a package](add-a-package.md).

[The application layout](application-layout.md) describes each file that the
application contains.

To use one package without an application, install it with `uv add`. The
README of each package shows how to use it alone. The
[Components](../components/index.md) page has a link to each README.
