# Security policy

## Supported versions

Every `xtr-*` package is released at one shared version. Security fixes go into the latest
release only, so upgrade to it.

## Reporting a vulnerability

Please report vulnerabilities privately, through
[GitHub's private vulnerability reporting](https://github.com/xterr/python-xtr/security/advisories/new)
on this repository — not in a public issue, and not on the read-only `python-xtr-*` repositories.

Include the affected package and version, what an attacker can do, and how to reproduce it. You
will get an answer within a week, and credit in the advisory once a fix is released.
